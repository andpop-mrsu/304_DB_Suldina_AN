# Описание структуры файлов данных

В папке Task01 находятся исходные файлы данных, скопированные из каталога `dataset`, и файлы, созданные в ходе выполнения работы. Ниже приведено описание всех файлов.

## ratings.csv
Формат: CSV, разделитель - запятая, первая строка - заголовок.

| Столбец   | Тип      | Описание                                      |
|-----------|----------|-----------------------------------------------|
| userId    | целое    | Идентификатор пользователя                    |
| movieId   | целое    | Идентификатор фильма                          |
| rating    | дробное  | Оценка пользователя (от 0.5 до 5.0)           |
| timestamp | целое    | Время выставления оценки                      |

## movies.csv
Формат: CSV, разделитель - запятая, первая строка - заголовок.

| Столбец | Тип     | Описание                                      |
|---------|---------|-----------------------------------------------|
| movieId | целое   | Идентификатор фильма                          |
| title   | строка  | Название фильма (включая год выпуска)         |
| genres  | строка  | Жанры, разделённые символом `|`               |

## tags.csv
Формат: CSV, разделитель - запятая, первая строка - заголовок.

| Столбец   | Тип      | Описание                                      |
|-----------|----------|-----------------------------------------------|
| userId    | целое    | Идентификатор пользователя                    |
| movieId   | целое    | Идентификатор фильма                          |
| tag       | строка   | Текстовый тег, присвоенный пользователем      |
| timestamp | целое    | Время присвоения тега                         |

## users.txt
Формат: текстовый файл, разделитель - вертикальная черта (`|`), заголовка нет.

| Поле       | Тип     | Описание                                      |
|------------|---------|-----------------------------------------------|
| id         | целое   | Идентификатор пользователя                    |
| name       | строка  | Полное имя пользователя                       |
| email      | строка  | Адрес электронной почты                       |
| gender     | строка  | Пол (male / female)                           |
| date       | дата    | Дата в формате YYYY-MM-DD                     |
| occupation | строка  | Род занятий (профессия)                       |

## occupation.txt
Формат: текстовый файл. Каждая строка - название профессии или рода занятий

## genres.txt
Формат: текстовый файл. Каждая строка - название жанра

## ratings_count.txt
Формат: текстовый файл. Содержит две строки:
1. Минимальный идентификатор пользователя из `ratings.csv` и количество строк с этим идентификатором.
2. Максимальный идентификатор пользователя из `ratings.csv` и количество строк с этим идентификатором.

## sqlite.txt
Формат: текстовый файл. Содержит информацию об установленной версии SQLite и доступных режимах вывода в утилите `sqlite3`.
